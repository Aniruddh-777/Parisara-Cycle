Internship Period: May 4, 2026 to May 20, 2026

Project: Parisara-Cycle Android Application

Platform: Kotlin, Jetpack Compose, Firebase-ready Android app

Project overview: Parisara-Cycle is an Android application for bicycle commuters. It helps riders sign in, choose a route, report danger zones, view nearby pit-stops, track CO2 savings, and optionally share live location with nearby riders.

Current project mode: The app supports a no-key local mode using local authentication, local danger-zone storage, mock pit-stops, demo buddy markers, local route generation, and local eco-stat storage. Firebase and Google Maps/Directions can be connected later through configuration files and API keys.
