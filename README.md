ParisaraCycle 🚴‍♂️🌱
Overview

ParisaraCycle is an Android application developed as part of an internship project focused on Android App Development using Generative AI. The application promotes eco-friendly transportation by encouraging cycling and helping users track cycling-related activities, environmental impact, and nearby pit stops.

The project was developed using Kotlin and Android Studio with modern Android development practices.

Features
🚴 Cycle activity tracking
📍 Map integration for navigation and pit stops
📊 Eco statistics and environmental impact tracking
🧭 Nearby pit stop management
📱 Modern Android UI using Jetpack Compose
🔥 Firebase integration
🗂 MVVM Architecture
⚡ Smooth user experience and responsive UI
